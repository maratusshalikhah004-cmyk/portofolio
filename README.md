# Personal Portfolio Website — Mar'atus Shalikah

Welcome to my personal portfolio website! This project showcases my journey as an Informatics student, highlighting my technical skills, academic achievements, certifications, and hands-on projects. It reflects my continuous learning process and passion for exploring different areas of computer science.

The website features a clean, minimal design with responsive layouts, smooth animations, and an intuitive user experience.

Visit the live website here:

---

## ✨ Key Features

- **Responsive Design** — Optimized for desktop, tablet, and mobile devices.
- **Sticky Navigation** — Blur-transparent navigation bar with smooth scrolling effects.
- **Responsive Hamburger Menu** — Custom mobile navigation with animated menu transitions.
- **Scroll Reveal Animations** — Content gracefully fades and slides into view while scrolling.
- **Interactive UI Elements** — Hover effects and subtle animations for projects, certificates, and navigation links.
- **Modern & Minimal Interface** — Built with readability, accessibility, and simplicity in mind.

---

## 🛠️ Tech Stack

- **HTML5** — Semantic and accessible markup.
- **CSS3** — Flexbox, CSS Grid, responsive layouts, custom animations, and media queries.
- **JavaScript (Vanilla)** — DOM manipulation, navigation interactions, and animation controls.
- **Google Fonts** — _Playfair Display_ & _DM Sans_.
